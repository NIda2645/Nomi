用 Brainstorm 找方向

TapNow Creative OS 的生成前创意开发入口，帮助你通过对话发展剧本、角色、世界观和广告方案。

头脑风暴是 TapNow Creative OS 的创意开发入口，适合生成前的阶段。你可以从一句模糊想法、一份客户 Brief 或一张参考图开始，通过和 Agent 对话，把剧本、角色、世界观、广告方案和视觉方向一步步发展清楚。

这个过程更像共同推进一场创作游戏：Agent 提问或给出候选，你直接选择、否定或组合，Agent 再沿着你的选择继续推演。聊天用来激发创意，Agent 负责整理创意，画布则保存已经确认的人物、设定、参考和故事节点。

每次对话都会补充后续制作需要的上下文。方向确认后，Agent 可以继续整理剧本、HTML 页面、Pitch Deck 等成果，也可以把画布上的内容交给后续图片和视频制作。

头脑风暴是怎么工作的？

一轮完整的头脑风暴通常包含四步：

给出起点：告诉 Agent 现有想法、Brief、参考素材或需要解决的问题；
一起推演：Agent 持续提问并给出候选，你直接选择，或按需要补充限制；
同步到画布：角色、世界观、剧情节点、视觉参考和关键决定被整理成画布节点；
整理成果：把确认的内容转成剧本、分镜、HTML 页面、Pitch Deck 或后续生成任务。

你随时可以回到画布查看已经确认的内容，不需要在很长的聊天记录里重新寻找。后续生成偏离方向时，也能直接引用对应节点继续修改。

头脑风暴可以用来做什么？
剧本开发：发展故事起点、人物关系、剧情结构和关键场景；
角色与世界观：定义人物背景、行为动机、世界规则和视觉基调；
广告方案：从客户 Brief 出发，比较创意路线、受众角度和表现形式；
网络搜集与灵感参考：查找公开资料、案例、视觉风格和创作线索；
影视拆解与镜头研究：分析作品结构、镜头语言、节奏和场面调度；
场景美术布局：规划空间关系、主体位置、光线和环境元素；
网页 Demo：把创意整理成可以打开预览的 HTML 页面或互动原型。

如果脚本、镜头和参考已经全部确定，直接让 Agent 进入制作会更快。

头脑风暴会留下什么？

头脑风暴不会只留下一段聊天记录。它会把过程中确认的信息整理到画布，并根据任务生成：

创意简报、故事大纲和完整剧本；
人物设定、关系图和世界观说明；
镜头研究、场景布局和视觉参考；
分镜、镜头表和后续制作任务；
可预览的 HTML 页面或网页 Demo；
面向团队或客户的 Pitch Deck。

不同账户能生成的文件类型可能不同，以当前页面显示的按钮为准。

先告诉 Agent：

最终要交付什么；
面向谁；
必须保留的内容；
不想出现的方向；
希望比较几个候选。

复制这个指令给 TapNow Agent 试试

Brainstorm

我要为一款户外音箱做 15 秒广告，我会发产品参考图给你，我需要给喜欢露营的年轻人看。必须让人看出它防水、方便携带。先给我 3 个明显不同的方向，每个方向写清一句话点子、主要场景、观众会感受到什么、产品怎么出现，以及 4 个镜头。先不要生成视频。

2. 和Agent一问一答地推进

头脑风暴适合一问一答地往前推进：

Agent 提出一个关键问题或少量候选；
你直接选择、否定或组合；
Agent 根据你的选择继续问细节；
把选定的内容写入画布；
当方向足够清楚时，再转入制作。

如果问题太多或偏离目标，可以直接使用：

Brainstorm

先暂停追问。请汇总目前已经确认的内容、仍未确认的问题，以及你建议的下一步。不要继续扩展新方向。

复制

好的追问应该帮助你做决定，例如“先突出防水还是便携”，而不是让你补写一份完整策划案。如果 Agent 连续追问已经写在 Brief 里的信息，重新引用 Brief，并让它先列出已知条件。

3. 让候选方向真正不同

如果三个方向只是换了颜色，可以让 Agent 从下面几处重新拉开差异：

是朋友聚会、雨天露营，还是一个人放松；
是讲一个小故事，还是直接展示卖点；
是实拍质感、动画，还是口播讲解；
节奏是轻快、紧张，还是安静；
产品是自然出现在故事里，还是作为主角被展示。

不要一次要求十几个方向。先得到少量、可比较的候选，再深入。

4. 把决定留在画布上

让 Agent 把已确认内容分别写成：

创意简报；
脚本或镜头表；
角色、产品和场景规则；
视觉参考；
待生成的图片或视频任务。

画布上只保留会继续使用的内容。还要比较的放在“待确认”区，已经放弃的方向移到一边，别让 Agent 后面误用。

建议给确认内容加上能说明状态的标题，例如“已确认｜户外音箱夜间方向”和“待确认｜结尾产品特写”。以后新建对话时，只需要引用这些节点，就能从已做出的决定继续。

5. 方向确定后再生成

让 Agent 根据已确认方向输出一份制作计划，至少包含：

先在画布上创建哪些节点；
每个节点要使用哪张图、哪段文字；
图片和视频分别准备使用哪个模型；
哪些步骤会消耗 Tapies；
运行到哪里先停下来让你确认。

可以直接说：

Brainstorm

基于画布上已确认的方向，整理一份制作计划。先生成角色标准、场景参考和 4 个静态分镜；我确认后再生成视频。不要继续使用已放弃的方向。

复制
头脑风暴偏离方向时怎么办？
候选越来越相似：要求从受众动机、叙事结构或媒介形式拉开差异；
内容越来越多：让 Agent 只保留与交付目标有关的决定；
旧方向持续干扰：新建对话，并只引用已确认的画布节点；
无法选择：先定义 3—5 个评价标准，再让 Agent 按标准比较；
太早开始生成：切回手动确认，先完成脚本和视觉标准。
哪些内容仍然需要你决定？

头脑风暴可以补充选项和推演结果，但下面几项最好由你明确确认：

哪个方向最符合真实受众，画面也能支持这个方向；
产品卖点有没有被夸大或错误表达；
候选使用的参考素材是否可以继续使用；
方向是否能在当前时间、预算和交付规格内完成；
哪些结论已经定稿，哪些仍然允许变化。
什么时候可以进入制作？
只有一个明确的主方向；
画布上有脚本或镜头结构；
必须保持的产品、角色和风格规则已经写清；
下一步要生成的内容和验收方式明确。
