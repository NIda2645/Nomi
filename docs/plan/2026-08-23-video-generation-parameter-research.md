# 视频生成模式与参数调研计划

## 目标

回答一个用户价值问题：用户只描述想要的镜头效果时，Nomi 如何在不要求用户学习供应商参数的前提下，选择合适的生成模式、模型参数和参考素材，并且允许用户像编辑 UI 一样自由调整。

## 研究范围

1. TikHub 公开短视频样本：按“AI 视频提示词”“AI 运镜模式”“AI 短视频生成教程”搜索，抽取少量公开元数据和 540p 样本，分析真实用户反复表达的任务目标。
2. 顶尖产品官方文档：Google Veo、Runway、MiniMax、Luma 的模式、参数、输入约束和提示词建议。
3. 顶尖开源实现：Wan、Diffusers、ComfyUI/MotionCtrl 等，核对控制信号和模块边界。
4. 原始论文/基准：实体一致性、相机/主体运动控制、长片诊断、视频质量维度。
5. 结合 Nomi 当前生产运行与 MCP 方案，提出通用的意图层、能力层、参数选择层、质量验证层规格。

## 不做

- 不把某个供应商的字段直接变成 Nomi 公共 UI。
- 不凭 TikHub 热门教程的单条经验宣布某个参数普遍有效。
- 不在本轮接入真实付费生成或自动替换用户选择。

## 证据与验收

- 每条结论标记为观察到的事实、官方文档事实、论文结论或 Nomi 设计提案。
- 不保存 API key；原始 TikHub 数据和样本只放在 `/tmp/nomi-video-research-20260823`。
- 研究报告给出：模式/参数决策矩阵、供应商能力差异、缺失能力降级规则、真实用户任务测试矩阵和下一阶段决策点。
- 只在证据和用户价值链路明确后，另开实现计划；本轮不改生成代码。
