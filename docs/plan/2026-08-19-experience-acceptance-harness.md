## 一、三层金字塔（每层测什么、花什么、何时跑）

| 层 | 是什么 | 额度 | 何时跑 |
|---|---|---|---|
| **L1 机制层** | 单测：每个新机制的行为矩阵（审片重试分支、冻结门拒发、信任计数、收敛 schema） | 零 | 每次 commit（gates 内） |
| **L2 旅程层** | `tests/ux/draft-journey.e2e.mjs`：真 GUI + 真 stdio MCP 子进程 + mock vendor + **stub 判分器**，六幕全流程走通，断言体验指标 | 零 | 每波交付前 + gates 可挂 |
| **L3 真实体验层** | **我扮演真实用户**：在本机真实桌面端客户端（Claude 桌面端 agent 会话，就是现在这种）经 `mcp__nomi__*` 驱动**装机版** Nomi，真 vendor 真生成，产物逐个亲眼 Read，质量按判据打分 | 真额度（见预算表） | 每波合 PR + 重打包装机后；最终 F1 全旅程 |

L2 与 L3 的分工：L2 证「流程对」（零额度可反复跑），L3 证「质量真」（真模型真像素）。审片判分在 L2 用 stub（按 prompt 关键词返回低分，验重试路径被走到），在 L3 用真 VLM（验判得准）。

**L3 硬前提（记忆里栽过的坑）**：MCP server = 装机版 app 二进制。每波 L3 验收前必须：合 PR → 重新打包安装 `/Applications/Nomi.app` → 重启客户端；并用 `grep -a <新代码特征串> app.asar` 实证装机版含本波改动，再开测。

## 二、六幕 × 断言表（完成的定义）

| 幕 | 机制 | L1/L2 断言（零额度） | L3 断言（真额度+人眼） | 点亮波次 |
|---|---|---|---|---|
| 0 开场收敛 | 一屏 ≤3 题 elicitation（enum 候选 + 按你判断） | 收到恰好 1 次 elicitation；含 3 题带候选；「按你判断」路径直通不再问 | 我作为用户体感：回答一屏后全程不再被问方向 | W3 |
| 1 剧本+圣经 | writer 技能 + 全资产大师 V3.0 → 编号场景 + 圣经字段 | 产物含编号场景与圣经（static/dynamic/禁改字段齐）；指改 `#N` 静默生效（零弹窗）+ 回执 | 剧本可读、圣经像人话；指改一句话生效 | W2（圣经字段）/W3（指改语义） |
| 2 定妆冻结 | 冻结门：未冻结拒批量；冻结后强制引用 | 未冻结时批量生成被拒（结构断言）；冻结后 12 镜引用齐全；冻结确认恰 1 次 | 定妆照真好看过关（人眼）；冻结后无一镜丢参考 | W2 |
| 3 分镜表 | StoryboardPlan 落画布 + 编号镜头列表输出 | 分镜含镜号/景别/时长/引用锚；`#N 改成…` 改到对应节点且引用不变 | 分镜读起来像分镜师写的（对照 director 技能 rubric） | 今天可部分绿 |
| 4 批次确认闸 | 逐镜清单 + 总额度（含审片预算）一次批准 | 恰好 1 次批次确认；含镜数与预算字段；批准后到交付零打断；拒绝则零 vendor 调用 | 账单和实花对得上（±20%） | W1（预算披露）/W3（批次形态） |
| 5 生成+审片 | k=2 选优 + 定向重试 ≤3 + 进度帧 | **注入坏判分的镜头 100% 走到重试**；重试仍败 → 交付带红标；进度帧含「N/M·审片状态」；完成有系统通知 | 真 VLM 判分：注入坏参考的镜头被检出；identity ≥4/5 占比 ≥80% | **W1** |
| 6 交付 | 体检报告：过检数 + 红标 + 建议 + 价格 + 深链 | 结果结构含 passed/flagged/建议/深链；`重滚 #N` 只重生成该镜 | 交付物崩坏数 = 0（崩的都被标红）；剩余问题全是品味级 | W1 |

**全程横切指标（L2 机器断言 + L3 体感复核）**：Block 确认 ≤4 次；指改零弹窗；App 弹窗 0 次（elicitation 客户端）；生成期间可离开（进度帧 + 通知齐）。

## 四、「符合预期」的硬判据（不许拍脑袋说好了）

**流程 4 条（L2 机器可判）**：① Block 确认 ≤4；② 指改零弹窗；③ 生成期零强制盯屏（进度帧间隔 ≤30s + 完成通知）；④ 交付报告结构完整（过检数/红标/建议/价格/深链缺一不可）。

**质量 3 条（L3 真判分）**：⑤ 交付物中未标红镜头的 identity/composition/continuity 三轴均 ≥3.5/5（shotVerify 口径）；⑥ 人为注入的坏镜头检出率 100%；⑦ 同角色跨镜 identity 均分 ≥4/5。

**人眼 1 条（最终闸）**：⑧ 我逐个 Read 产物（截图/视频帧），按「崩坏 vs 品味」分类——**交付物里未被标红的崩坏 = 0** 才算过；最后把成片和判分报告交用户过目，用户点头才关闭。

判据⑤⑦的阈值来源：shotVerify 现行 3 档过线 + ViMax/FilmWorld 实测参数，第一轮 F1 后按真实分布校准一次（写回本文档，只许更严不许放松）。
