# Agent 界面样张 v3 · 逐屏走读（给用户念的版本）

> 日期：2026-09-02 · 配套样张：`docs/design/mockups/2026-09-01-agent-ui-final-redesign.html`（桌面拷贝：`~/Desktop/Nomi-Agent界面重做样张.html`）
> **v3 是什么**：你看完 v2 给了九条整改 + 一句总纲——「这个 agent 要长得像住在对话里的 Claude Code：一切事件进对话流，常驻栏越薄越好」。v3 = 照单全改。
> **怎么看样张**：浏览器打开，顶上四个页签切屏；右上角「暗色」切亮暗、「标尺」给所有可点的东西描虚线框（用来数每屏有多少可点）。屏 A 里工具那几行的行尾小箭头**真的可以点**，点了会展开。
> **本文怎么读**：每屏一节，屏里每个东西一条，每条讲三件事——这是什么 / 为什么这样 / 你什么时候会碰它。

---

## 屏 A · 主对话流（平时用得最多的那个面）

### 1. 顶部一行（面板的「头」）
- **这是什么**：整个头只剩一行：左边 N 标 + 「Nomi」；旁边一颗小胶囊写「还能聊 ~40 轮」；最右边两个小图标——历史对话、收起面板。
- **为什么这样**：你点名删的两样都删了（整改⑧）：「· 雨夜追逐」项目名没了（顶栏本来就写着，这里重复）、「当前现场」标签没了（没有任何行动价值）。v2 顶部那颗常驻的「按 编剧·Kasdan」技能标记也没了（整改①②，见第 5 条）。头从三行变一行。
- **那颗胶囊**：平时只说一句人话「还能聊 ~40 轮」——告诉你这轮对话还有多少余量。鼠标放上去才展开明细：本轮用了多少、累计多少、这个对话花了多少钱。不想知道的人永远不会被这些数字打扰。
- **你什么时候碰它**：想翻旧对话点历史；想让画布占满点收起；担心「聊太久它会不会忘事」时瞟一眼胶囊。

### 2. 「前面 24 轮已折叠 · 展开」细线
- **这是什么**：聊久了，Nomi 会把很早的对话收起来省地方。这条细线告诉你收了多少，点「展开」原地翻开。
- **为什么这样**：不给这条线，收纳发生那一刻你只会觉得「它怎么突然失忆了」。
- **你什么时候碰它**：长对话里想翻旧账的时候。

### 3. 「进入 · 生产段」工序线
- **这是什么**：对话从「聊剧本」推进到「动手生成」时画的一道分隔线，带一个小图示。
- **为什么这样**：做视频有固定几道工序（写剧本→拆镜头→搭画布→出片→上时间轴），这条线让你抬眼就知道走到哪一道了。v3 里它是静态的——整个屏幕同时只有「正在干活」的那一行在动，别的都安静（动效极简）。
- **你什么时候碰它**：不用碰，扫一眼定位进度。

### 4. 你的消息（右侧黑底气泡）
- 跟所有聊天软件一样，不解释。

### 5. 「⚙ 载入 编剧·Kasdan」灰字小行
- **这是什么**：Nomi 给自己装上一套写作方法的那一刻，在对话里记一笔。灰字、小号、不是卡片。
- **为什么这样**：整改①②。v2 在顶部和输入框上方**各有一块**常驻的「技能已装载」，跟这行三处重复——现在只留对话流里这一处。这正是 Claude Code 的真实做法：装载是对话里发生的一件事，发生了、记下了、过去了，不占常驻位。
- **你什么时候碰它**：好奇「它怎么突然换了个写法」时，往回一翻就看到是从哪行开始的。

### 6. 「想了 4 秒 · 拆成 5 镜，2 镜要站位参考」
- **这是什么**：Nomi 想完之后留下的一句小结。行尾有个小箭头，点开能看它当时的思路。
- **为什么这样**：想的过程结束后不凭空消失，落成一句结果留在原地——你随时能查「它凭什么这么定」。
- **你什么时候碰它**：对它的决定有疑问的时候。

### 7. 正文回复
- Nomi 说的话，纯文字。正在生成时末尾有个小光标在闪。

### 8. 「6 步 · 读剧本 · 拆 5 镜 · 生成 2 图 ▾」工具总览行
- **这是什么**：Nomi 这一轮干的所有活，收成一行。点行尾小箭头展开每一步：「✓ 读了剧本 · 2400 字」「✓ 拆成 5 镜」「✓ 生成 2 张参考图 · 0:41」。样张里真的可以点。
- **为什么这样**：整改⑤。v2 是一块带边框底色的面板区，删了。Claude Code 的真实样子：每个工具一行、可展开、干完收拢成一行总览。活干完了就不该继续占地方。
- **你什么时候碰它**：想核对「它到底动了什么」的时候点开。

### 9. 「✓ 已加 5 个节点」+ 行尾小 ↩
- **这是什么**：Nomi 把东西写进画布后的绿色回执。右侧一个小 ↩ 图标，鼠标放上去显示「撤销这一笔」。
- **为什么这样**：整改⑦「能 icon 不用字」——撤销是随手动作，收成图标不占字。
- **你什么时候碰它**：这批不想要了，点一下整批退掉。

### 10. 黄色「撤销会丢掉你改过的东西」确认卡
- **这是什么**：只在一种情况出现：你点了撤销，而这批里有你**手动改过**的东西。它列明会丢什么（「镜 3 的提示词你改过：暖光→冷调」），再问一次「再想想 / 仍要撤销」。
- **为什么这样**：整批撤销会连你自己的修改一起退掉——这种事必须先说清再动手。平时这张卡根本不出现。
- **你什么时候碰它**：撤销撞上自己改过的东西时，仅此一种。

### 11. 「2 张参考图在「参考」分类 · 去看」小胶囊
- **这是什么**：告诉你产出落到了哪里，点了直接跳过去。
- **你什么时候碰它**：想看图落哪儿了。

### 12. 「正在重画第 4 镜参考图 0:12 ▾」进行中行
- **这是什么**：当前正在干的活。一行：转圈小图标 + 一句话 + 已用时间，行尾小箭头点开看这轮已完成的步骤。
- **为什么这样**：整改⑤。同一行会原地从「排队」变「进行中」变「完成」，不会刷出三行来。没有百分比就不画进度条（画了也是假的）。
- **你什么时候碰它**：等的时候看一眼它在干嘛、干了多久。

### 13. 输入框上沿的浅色排队行
- **这是什么**：Nomi 忙的时候你继续发的消息，一条一行、浅色、贴在输入框正上方。轮到它就自动进对话开始执行；点右边小 × 撤回。
- **为什么这样**：整改④。v2 那张带编号、带一排管理按钮的「任务队列卡」删了。Claude Code 的真实样子就是这样：排队消息是几行浅色字贴在输入框上沿，无卡片无边框。
- **你什么时候碰它**：你说得比它干得快的时候——尽管说，不用等。

### 14. 输入框（@ 是唯一的引用手势）
- **这是什么**：打 `@` 弹出选择器，素材、角色定妆、视频片段、技能都从这里选；选完变成句子里的一个小色块。样张里演示了两个：蓝色的 `@阿青定妆`，和黄色的 `@街道 02:10`——黄色的意思是「你引用之后这段素材被改过，发送时会用现在这一版」。
- **为什么这样**：整改③。v2 输入框上面常驻一排「引用架」（定妆槽、素材 chip、加号按钮），全删了。引用就一个手势：@。引的东西就长在你的句子里，看得见、删得掉。
- **你什么时候碰它**：想让 Nomi 参照某张图、某段素材、某套方法的时候。

### 15. 底部一排按钮（5 个，一个不多）
- **这是什么**：📎 附件 · ⚡「Agent · 安全自动」 · 🤖 文本模型 · ✏️ 提示词模板 · ↑ 发送。
- **⚡ 那颗管什么**：Nomi 的权限，两件事收在同一个入口里——它能动什么（只回答 / 只改选中的 / 全能动），和它问你多少（步步问 / 安全的自动做 / 全放行）。
- **🤖 那颗管什么**：Nomi 用哪个文本模型来理解和规划。没选过时按钮直接写「去选文本模型」，不给你看一串代码（修掉了 v2 之前露出内部代号的问题）。
- **你什么时候碰它**：发消息每次都碰 ↑；其余偶尔调一次就不动了。

**屏 A 的账**：常驻可点 **19 → 10**（头 4→3、排队区 5→1、输入区 10→6）。删掉的 9 个没有一个是失去功能——都是重复入口或换了更薄的形态。

## 屏 B · 要你做决定的卡（六张）

这些卡都出现在对话流里，决定完就随聊天滚走。v3 对这屏做的事：**所有字过一遍人话闸**（整改⑥）、卡里的设计注释小字全部挪出卡外（整改⑨）——卡里只剩你真会用到的东西。

### 1. 计划卡「拆成 5 镜 · 生成计划」
- **这是什么**：Nomi 要批量生成前先给你过目的单子。上面两颗药丸是这批的公共设置（用什么模型、什么画幅），下面每镜一行：勾选框 + 镜头名 + 一句画面描述。哪行你单独改过，行尾会标「已改 · 还原」。
- **为什么这样**：直接复用现役画布里那张计划卡（一致性，不另造）。v2 这里有个重复：「竖版」出现了两次，修掉了。按钮从「确认全部（2 镜）」改成「生成已选（2 镜）」——勾了 2 个就说 2 个，不说「全部」。
- **你什么时候碰它**：每次让 Nomi 批量生成，先看这张单子再放行。

### 2. 付费确认卡「确认生成 · 会花钱」
- **这是什么**：花真钱之前的最后一道闸。每一项单价列清、合计加粗；灰底那句写明「付费后就不能再改：镜头数、模型、时长、清晰度。提示词仍可改」；确认按钮上直接带金额「确认并生成 ¥1.26」。
- **为什么这样**：竞品连「失败扣不扣钱」都不写，我们反着做——全部明示。v2 这张卡上有个「本会话不再提示」勾选框，v3 删了：**Nomi 自动干活时花钱，每次都得问你**；那个「不再提示」的开关只在你自己亲手点生成的场合才有（因为那时你清楚自己在花钱）。「过闸后」这种内部话也改成了「付费后」。
- **你什么时候碰它**：每次要花钱，必然碰。

### 3. 有出入卡「做完了，有 2 处和你批准的不一样」
- **这是什么**：Nomi 干完后自己对账，发现结果跟你批准的计划不一致时才出现的黄边卡。每条出入说人话：「镜 2 结尾的画面没接到镜 3 开头——中间那条连线生成时丢了」「阿青的头发画成了棕色，和定妆不一样」。三个选择：让 AI 修 / 撤销这一步 / 知道了。
- **为什么这样**：这是 Nomi 独有的形态（对过的竞品全都没有）——别家做完就完了，对没对上没人管。v2 这里写着「校验分 0.62，低于阈值」，这种话删了，直接说哪里不一样。**一切正常时这张卡永远不出现。**
- **你什么时候碰它**：只在结果跑偏时。

### 4. 反问卡「开始前问你 2 件事」
- **这是什么**：Nomi 觉得信息不够时先问你。一次只显示一个问题，选项竖排成按钮（键盘按 1/2/3 也行），角落写着「1 / 2」告诉你还有一问，可以「跳过」。
- **为什么这样**：一屏一问，想一件事就好（照 Beautiful UI 的确认卡整件搬的）。最多合并 3 问，绝不连环轰炸。
- **你什么时候碰它**：你的指令有歧义时。

### 5. 多候选卡「镜 1 · 3 个候选」
- **这是什么**：同一个请求出了几版结果，并排摆开，点缩略图就是选中（不设「上一个/下一个」按钮），底下一颗「采用 A 版」。采用之前它们只是候选，不动你的画布。
- **你什么时候碰它**：一次要了多版、挑一版的时候。

### 6. 产物卡 + 失败卡
- **产物卡**：标题行 = 「镜 1 · 1024×1792 · 第 2 版」+ 右侧动作（改提示词 ✏、重新生成 ⟳ 两个图标，「去画布」文字钮）；下面是完整缩略图，**任何按钮都不压在图上**。v2 写的「v2」现在说「第 2 版」。
- **失败卡**：红边。一句人话原因（「当前模型没配置好，这一步没跑起来」）+ 绿字明说「**这次没扣钱**」+ 三条出路：换模型重试 / 改提示词 / 看详情（原来叫「看日志」，改了）。
- **你什么时候碰它**：每次生成完 / 偶尔失败时。

**屏 B 的账**：七张卡平均可见选择 **4.3 → 4.0**；卡内设计注释小字 **5 处 → 0**。

## 屏 C · 右栏换班（过渡期的临时规矩）

拆解表和 Nomi 对话现在共用右边那条栏，同一时刻只住一个。这屏演示两个方向的「换班」：

### 左半：Nomi 在栏里，拆解表去哪了
- 拆解结果收成源视频节点上的一个小浮条「拆解结果 · 5 镜」，节点头顶挂蓝色小标「✓ 已拆解 · 5 镜」。点浮条，表就回来。
- **为什么放节点上**：拆解结果本来就属于那条视频，跟着它走最好找（一个功能一个家）。
- 对话里 Nomi 调用拆解的那条记录，也是屏 A 同款的一行式（v2 里的内部话「(M 线后)」这类全删了）。

### 右半：拆解表在栏里，Nomi 去哪了
- Nomi 收成顶栏一颗小角标「● 进行中」；它有新动静（回复了、干完活了）就冒蓝点。点角标，对话回来。
- **为什么放顶栏**：顶栏是唯一在创作/生成/预览三个页面都在的地方，Nomi 收哪儿都不会丢。

### 换班的规矩
- 切换 260 毫秒滑入滑出，不闪跳。
- **收起只是收起，不清空**：你勾了一半的镜、滚到一半的位置、正在跑的任务，换班回来原样都在。

**你什么时候碰它**：拆完一条视频又想跟 Nomi 说话（或反过来）的时候。这套「换班」是临时的——等下一屏的形态落地它就消失。

## 屏 D · 终局：结果固定在上、对话在下（不再换班）

### 1. 顶部一行
- 跟屏 A 完全一样：Nomi + 用量胶囊 + 两个图标。

### 2. 固定在对话上方的「拆解结果」卡
- **这是什么**：拆解出的 5 镜表格，固定停在对话上方，**不随聊天滚走**。卡头一枚小 📌 说明了一切——没有任何「结果卡区 · 固定」之类的标签文字（整改⑧：界面自己长得像什么，就不用再写字解释什么）。
- **里面有什么**：每镜一行：勾选框 + 缩略图 + 镜头名 + 时间 + 画面描述 + 这镜的字幕；镜 3 画面没读出来就红字直说「这镜没读出来 · 可单独重试」。底部：「用这套结构起稿」「已选 2/5」「加入画布 (2)」。
- **为什么固定**：拆解表是要**对着它反复操作几十分钟**的东西——勾选、对照、改——不能让它被聊天冲走。过程性的东西（问答、进度）都在下面的对话里滚。竞品手册里用户自己都说：「不想在很长的聊天记录里重新找已确认的内容」。
- **你什么时候碰它**：照着别人的片子做自己的版本时，这就是你的工作台面。

### 3. 下面的对话流
- 你的请求 → Nomi 的一行工具记录「拆解视频 · 5 镜 · 1 镜没读出来 ▾」（点开看它逐帧看画面、写描述的步骤）→ 一句回复。跟屏 A 同一套语言。
- 节点上的浮条和对话里的这行工具记录，指向的是**同一张**固定卡——不管从哪边进来，看到的都是它。

### 4. 输入框
- 同屏 A：@ 引用、5 颗按钮。占位文字提醒「输入 @ 可以引素材或技能」。

**屏 D 的账**：常驻可点 **12 → 10**（头部瘦身）。屏 C 的换班规矩到这一屏自动作废。
