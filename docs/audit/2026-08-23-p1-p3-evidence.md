# P1→P3 MCP 可编辑单镜生成阶段证据

日期：2026-08-23  
分支：`codex/p0-runtime-foundation-20260822`  
范围：P1/P2 边界与 P3 零 provider-quota seam；真实 provider smoke 尚未开启。

## 用户价值结论

- P1 解决“换模型/供应商/输入模式就要学习一套 Nomi 私有格式”的摩擦：模块、provider、model、mode、参数和素材都是声明数据；不支持时在 provider 前明确失败。
- P2 解决“我只是改了一个参数/换了参考图，却不知道系统实际提交了什么”的摩擦：candidate 每次编辑都生成新 revision/hash；字段被丢弃时有 warning/ledger；封存后编辑返回 `new_draft_required`，不会偷偷改原任务。
- P3 seam 解决“要离开 MCP 去 Nomi 点第二次、崩溃后怕重复扣费”的摩擦：provider-neutral adapter 只接受 sealed contract；envelope 先落盘；provider 已接受但回执丢失时只进入 reconcile，不盲重提。
