## 2 · 拿不到模型清单（#786）

**结论：已适配平台那条路上 #786 的承诺成立；但用户说的「接一个假中转站」这条路在这个包里根本走不到。**

### 2.1 已适配平台 + 错 key —— 成立

APIMart 连接页粘一把错 key → 点「保存验证」：

- **1040 ms** 就给了答复，抽屉**没关**，仍停在 `platformConnect` 页。
- 文案：`保存失败：密钥验证失败，请检查密钥和权限后重试。原密钥和连接已保留。`

截图：`c2-zh-A-filled.png` · `c2-zh-A-wrongkey-result.png`

### 2.2 假中转站地址 / 断网 —— 走不到

模型首页「已适配平台 + 更多已适配平台」一共列出 18 家，**全部是固定地址的预置平台**，连接页只有一个「粘贴平台 API Key」输入框，**没有可编辑的接入地址**：

```

runway, runninghub, volcengine-speech, replicate, comfyui-local,
dreamina-member, codex-local, local-text, antigravity-cli
```

「其他接入方式 / 高级与连接设置」下只有两扇自定义门：

- **「我已有调用脚本」** → `add` 页，页面自己写着「继续后只会建立一条不可生成的草稿，**不会抓文档、拉模型**、调用 AI 或发起付费验证」。填好「API 根地址 + Key + 模型 ID」点「继续填写」后，**60 秒内界面一个字都没多、页面也没换**（按钮大概是被前置校验挡住了，但没说缺什么）。
- **「高级 · 自定义普通 HTTP 请求」**。

源码里确实有一条带可编辑 base URL 的向导分支（`src/ui/onboarding/OnboardingWizard.tsx:495-530`，条件是 `selectedPreset?.custom`），但**从现在这个首页点不到它**。

所以「接一个假中转站 + 错 key，看抽屉关不关」这条用例，本轮**无法在真机上构造**——不是修没修好的问题，是这条路对用户不存在。这正好撞在用户长期反馈的「自己接模型太难」上。

截图：`c2-zh-01-home.png` · `c2-zh-B-all-platforms.png` · `c2-zh-B-custom-page.png` · `c2-zh-B-fake-relay-result.png` · `c2b-zh-01-drawer.png`

### 2.3 顺带撞到：打包版拒绝验证回环地址的供应商

给隔离实例种一个指向 `127.0.0.1` 的 loopback 供应商时，打包版返回
`暂时无法验证密钥，请检查接口地址和网络后重试。原密钥和连接已保留。`
—— 同样的种法在开发构建上是通的。这意味着**本机 / 局域网的 OpenAI 兼容网关按 key 接入，在装机版上会被挡**。这条是顺手撞到的，没有专门做对照，需要复核。

### 5.1 走查时撞到的、比 16 条更要紧的三件

这三件不在原清单里，但它们**盖住了**清单里好几条的可验证性：

- **A. 分镜面在 1280 宽视口下被横向裁切。** Agent 面板展开时，分镜编辑器列只有 **570 px**

  参考卡行的「+ 添…」全被切。有横向滚动条，但用户得先发现自己被切了。
  截图：`c5-zh-01-storyboard-editor.png` · `c5-zh-b01-clip-1280.png`
- **B. 行内模型下拉飞出分镜列、压住 Agent 面板。** 点某一镜的「默认模型」，浮层画到了右侧 Agent 面板上，
  盖住了「愿意 / 不分享」那张卡。截图：`c5-zh-b02-row-menu.png`
- **C. 行级「镜头操作」⋯ 按钮点了没反应。** 它是 15×15 px、`aria-label="镜头操作"`，两次点击（定位器 + 真实鼠标坐标）
  都没有任何菜单出现。这既是第 7 条判「仍在」的直接原因，本身也是一条要修的（连命中区都偏小）。
